Disturbances

The twenty IDV flags, read out of tepsim_core::FAULTS. Toggling one restarts the run from the beginning with the new scenario, and the page says so: a simulation takes its scenario at construction and these bindings do not invent a side door the native API does not have, because a run reachable only through the browser is a run nobody can reproduce.

Columns

A packed row is [hours, XMEAS(1..41), XMV(1..12)]. The identifiers are tepsim::channel_names; the labels and units come from tepsim_core::variables, which the core checks against the teprob.f header table.
